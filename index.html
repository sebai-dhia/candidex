A small tracker for a messy job search.

Designed for real application flow: save quickly, review clearly, and update responses without handing your data to another platform.

Slide-out workflow

Open Candidex over job boards, career pages, and search results without context switching.

Application dashboard

Track totals, response rate, success rate, platforms, countries, work types, and recent entries.

Response tracking

Search by company or role, then update status and interview dates when replies arrive.

Your data stays yours.

Candidex has no backend server and no hosted database. Your applications are written to a Google Sheet in your own Drive.

Privacy defaults
  • No analytics or telemetry.
  • No cookies or tracking pixels.
  • No client secret in source code.
  • OAuth through the browser identity flow.

Install from source.

Packaged store releases are not available yet. Opera is the primary target today.

git clone https://github.com/sebai-dhia/candidex.git
cd candidex
npm install
npm run build
  1. Open opera://extensions.
  2. Enable Developer mode.
  3. Choose Load unpacked.
  4. Select dist/candidex/browser.
