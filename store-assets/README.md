# Chrome Web Store listing assets

Generated by `npm run assets`. **These files are not bundled in the extension ZIP** — upload them manually in the [Chrome Web Store developer dashboard](https://chrome.webstore.com/devconsole).

## Upload checklist

| Asset | File | Size | Dashboard field |
|-------|------|------|-----------------|
| Store icon | *(in ZIP)* `public/icon-128.png` | 128×128 | Included in package |
| Screenshot 1 | [screenshot-1.png](screenshot-1.png) | 1280×800 | Store listing → Screenshots |
| Screenshot 2 | [screenshot-2.png](screenshot-2.png) | 1280×800 | Store listing → Screenshots |
| Screenshot 3 | [screenshot-3.png](screenshot-3.png) | 1280×800 | Optional (up to 5) |
| Screenshot 4 | [screenshot-4.png](screenshot-4.png) | 1280×800 | Optional (up to 5) |
| Small promo tile | [promo-small-440x280.png](promo-small-440x280.png) | 440×280 | Store listing → Promo tile (**required**) |

## Regenerate

```bash
npm run assets          # skip if outputs exist
npm run assets -- --force   # overwrite existing outputs
```

Source images in `landing/images/` and `public/candidex_logo.png` are never modified.
